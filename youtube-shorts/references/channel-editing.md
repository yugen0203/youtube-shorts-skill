# APIフィリピン不動産：標準の完成形

対象は @apigatewayph のみ。以下を既定にし、動画ごとに内容と文言を作る。特定のテスト動画の時刻・人物名・見出しを使い回さない。

## 構成

1. 冒頭3〜5秒：本人の結論を先出し。「結論／ダイジェスト」と明記する。
2. 本体：なぜその結論なのかを説明。離れた区間の連結可。条件・留保・否定を残し、因果関係を変えない。
3. 最後3秒：本編の実際のYouTubeサムネイルと「続きは本編を／チェック！」、下部に「下の関連動画をタップ」「↓↓↓」。無音の案内画面を追加する。

全体は通常30〜65秒を目安に、最後の3秒も含め最大180秒。明示された尺を優先する。

## レイアウト・文字

1080×1920、黒背景。16:9映像を中央に幅1080・高さ約608で配置し、映像や元字幕を切らない。

| 要素 | 1080×1920基準の設定 |
|---|---|
| 上部の主見出し | 太字123〜132px、赤FF2538、白縁FFFFFFを8px、影3px |
| 下部の要点 | 太字105px、黄FFE600、暗い縁161000を6px、影3px |
| 小カテゴリ | 白46px、y45 |
| 上部位置 | 3行ならy180、4行ならy125を目安に、映像開始y656より上に収める |
| 下部位置 | y1320付近から2〜3行、必要なら改行調整 |
| 条件の注記 | 灰C7C7C7、38px、y1710付近 |
| 署名 | 灰999999、32px、y1830付近 |

問い・対象・決め手が伝わる文字量を保つ。長文は小さくする前に文節で改行し、上部3〜4行、下部2〜3行を目安にする。重要な条件を省略しない。実際の引用でない要約を引用として見せない。上部・下部は説明に合わせて切り替える。元字幕が十分なら二重字幕を追加せず、下部は編集上の要点として使う。

フォントの字幅で収まりが変わるため、各表示状態を実フレームで確認する。縁取り、左右余白、中央の顔・字幕との重なり、注記との重なりを点検する。

## 編集プランとコマンド

スキル内の `examples/plan.json` を複製して、内容・時刻・sourceを実素材に合わせる。source/transcriptはプランからの相対パスを推奨。rangesの配列順に連結される。overlaysのstart/endは連結後の出力秒数。sourceの秒数と混同しない。

```sh
python3 "<スキル配置先>/scripts/compose.py" --plan ./plan.json --output-dir "/指定フォルダ" --name body.mp4
python3 "<スキル配置先>/scripts/endcard.py" --input "/指定フォルダ/body.mp4" --thumbnail ./source/thumbnail.jpg --out "/指定フォルダ/final.mp4" --source-url "https://www.youtube.com/watch?v=VIDEO_ID"
```

保存先は実行時の--out/--output-dirまたはSHORTS_OUTPUT_DIR。保存先未指定では停止。既存出力を上書きしない。日本語フォントはmacOSのHiragino Sansが既定。他OSではインストール済みCJKフォントをplan.fontとendcard.pyの--fontで指定する。

headlineとdescriptionは必須。post_titleが投稿タイトル。overlaysを指定すると固定headline/labelの表示を置き換える。headlineは記録用に残す。overlaysはtext、start、end、y、sizeを持ち、x既定540、color既定FFFFFF、outline_color既定000000。色はRGB6桁。borderは0〜16、shadowは0〜12、未指定は0。textはプレーンテキストと改行だけを使う。

字幕は元動画のsource_secondsから区間ごとにクリップ・累積変換する。区間外の発言を含む字幕の内容は自動修正されないため、編集前に照合する。composeはMP4・SRT・ASS・検証JSON・編集プラン・投稿文を出力。endcardは完成MP4・検証JSON・末尾編集プラン・投稿文・.publish.mdを出力する。本体のASS/SRTも編集用に保持する。

## サムネイル・本編へのリンク

元動画ID・チャンネルに一致する実サムネイルを取得し、目視確認する。1280×720を優先。取得不能ならユーザー提供の実サムネイルで続け、架空の画像で代替しない。自動で取得できなかった場合は未完了箇所を明示する。

endcard.pyは1080×1920・音声ありの完成動画に既定3秒の無音案内を追加する。元動画や既存MP4は上書きしない。画像・文字はクリック機能を持たない。

Shorts概要欄URLはクリックできないため、本編への導線はYouTube Studioの「関連動画」を使う。コンテンツ → 対象ショート → 関連動画 → 元動画 → 保存。上級者向け機能へのアクセスと、公開または限定公開の本編が必要。投稿・関連動画設定は依頼がある場合だけ行う。未設定なら.publish.mdを渡し、その事実を伝える。

公式仕様は運用時に確認する：
- https://support.google.com/youtube/answer/14075157?hl=ja
- https://support.google.com/youtube/answer/13748639?hl=ja

## 完成確認

冒頭・場面別テキスト・継ぎ目・末尾3秒の実フレームを確認する。ffprobeによる寸法・尺・音声、全編デコードも確認。聴感確認を実施できない場合は技術検証と区別して報告する。
